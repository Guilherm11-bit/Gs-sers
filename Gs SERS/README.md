
# Global Solution 2026.2 - SERS

## Neighborhood Action Dashboard

Projeto acadêmico desenvolvido para a disciplina de Soluções em Energias Renováveis e Sustentáveis (SERS), da FIAP.

### Objetivo
Desenvolver uma solução sustentável para iluminação de praças comunitárias, utilizando energia solar fotovoltaica, luminárias LED e sensores de presença.

### Tecnologias
- Python
- Streamlit
- Pandas
- Plotly

### Estrutura
- app.py: aplicação principal.
- dados/: dados de consumo energético.
- documentos/: relatório técnico.
- diagramas/: diagrama de funcionamento.
- requirements.txt: dependências.

### Como executar

Instalar as dependências:

pip install -r requirements.txt

Executar:

streamlit run app.py

### Indicadores
- Consumo energético.
- Economia percentual.
- Redução de custos.
- Participação de energia renovável.
- Emissões de CO2 evitadas.

### Observação
Os dados utilizados são estimativas acadêmicas e simulações, não medições físicas.
